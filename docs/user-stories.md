# User Stories

Format: As a [type of user], I want [goal], so that [reason or benefit].

1. As a customer, I want to view available cars and their rental prices, so that I can choose a car that suits my needs and budget.
2. As a customer, I want to book a car online, so that I can reserve a vehicle conveniently without visiting the rental office.
3. As an administrator, I want to manage car details and availability, so that I can keep vehicle information updated and prevent double bookings.
